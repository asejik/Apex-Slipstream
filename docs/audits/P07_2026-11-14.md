## 1. Engine Loop & Timing Discipline
- **Fixed-Timestep Physics:** Main loop uses a fixed $dt = 1/60\text{ s} \approx 0.01667\text{ s}$ physics tick with an accumulator capped at `MAX_ACCUMULATOR = 0.20s` to prevent the spiral-of-death on backgrounded tabs.
- **Rendering Interpolation:** Smooth camera damping and dynamic FOV speed pulse ($58^\circ \rightarrow 64^\circ$) interpolated per frame via `THREE.MathUtils.lerp`.
- **Hot-Loop Memory Hygiene:** Zero allocations (`new THREE.Vector3()`, closures, dynamic arrays) within physics update ticks or Three.js render calls. All scratch objects pre-allocated and reused.
