**P11-R01: no `<h1>`.**
- **Fix:** make the hub wordmark an `h1` with the same class.
- **Verify:** `curl -s https://apex-slipstream.pages.dev/ | grep -c "<h1"` gives 1.

**P11-R02: `/robots.txt`.**
- **What happens:** Cloudflare Pages answers unknown paths with `index.html`. Search engines treat an HTML robots file as "allow all", so nothing breaks.
- **Fix, if wanted:** add `public/robots.txt`.
