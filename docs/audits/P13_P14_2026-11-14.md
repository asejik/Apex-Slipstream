- **Hosting Platform:** **Cloudflare Pages** (Connected to `main` branch).
- **Production Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Production URL:** `https://apex-slipstream.pages.dev/`

### 2. Incident Response & Rollback Procedures
- **Instant Rollback:**
  - Navigate to Cloudflare Pages Dashboard $\rightarrow$ **Apex Slipstream** $\rightarrow$ **Deployments**.
  - Select previous successful deployment $\rightarrow$ click **Rollback to this deployment**. Rollback takes $< 10\text{ seconds}$ worldwide.
- **Git Rollback:**
  - `git revert HEAD -m 1 && git push origin main`.
- **Runtime Error Logging:**
  - Global error listeners in `src/main.ts` trap unhandled errors and promise rejections, displaying user-friendly `#error-banner` alerts without crashing browser execution.
