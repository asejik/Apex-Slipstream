## 4. Findings in detail

### P15-01 (HIGH): sprint races cannot be finished

- **Location:** `src/track/TrackSpline.ts` `buildCheckpoints()`:
  ```ts
  const t = i / checkpointCount;
  ...
  isFinishLine: i === 0,
  ```
  and `src/engine/LapManager.ts` `onCheckpointPassed()`, which only calls `completeLap()` at the `isFinishLine` checkpoint.
- **What's wrong:** on the two open tracks (`track_02_expressway`, `track_05_desert`, `isClosed: false`) the finish checkpoint is the start line. Driving to the finish gantry 1,100 to 1,300 m away does nothing.
- **Evidence:** driving every track's centreline start to end in a scratch copy with `LapManager`:
  ```
  track_01_coastal    type=circuit laps=3 raceCompleted=true
  track_02_expressway type=sprint  len=1164m start-to-end=1100m raceCompleted=false
  track_05_desert     type=sprint  len=1354m start-to-end=1300m raceCompleted=false
  (all six circuits: raceCompleted=true)
  ```
- **Impact:** the championship stalls at round 2. Breaks success criterion 3 in `PROJECT_PLAN.md` (complete an 8-race season).
- **Fix:** for open tracks, put the finish checkpoint at `t = 1` and make it last in sequence; stop AI cars at the end instead of wrapping. Add a test that drives a sprint to its end and expects `isRaceCompleted` (fails today).
- **Same pattern:** `AIDriverManager.update()` wraps `splineT % 1.0` and counts a lap on open tracks; `QualifyingManager.generateAIBenchmarks()` adds the closing segment back to the start, inflating AI times on sprints.
- **Verify yourself:** reach round 2 and drive to the finish arch. Nothing happens.

### P15-02 (HIGH): launch gate and audit reports do not hold

- **Location:** `docs/audits/P07/P08/P09/P11/P12/P13_P14_2026-11-14.md`, `docs/PROGRESS.md`, `docs/audits/FINDINGS.md`.
- **What's wrong:** all six reports were added in the same commit as the M8 feature code (`2379696`), each with zero findings and no command output. The findings register was empty, although PROGRESS.md says "Elevation / Clamping Fixed" and links to it. False claims are listed in section 8.
- **Impact:** the "10/10 gates passed, GO" decision was made without the checks behind it, which is how P15-01 shipped.
- **Fix:** re-run per section 10; record findings in the register.

### Medium and low

- **P15-03:** qualifying ends only when `lapManager.state.isRaceCompleted` (`src/main.ts:697`), i.e. after all race laps. In the browser, "Sector Sprint" on round 1 required 3 laps, same as "1-Lap Flying Shootout". `qualifyingMode` only labels the result.
- **P15-04:** at 844x390 and 640x360 the tire buttons sit at y=475 to 500, below the viewport (`#bottom-row` overflows `#ui-overlay`). Touch players cannot change tires.
- **P15-05:** `SurfaceType` is `asphalt | curb | gravel`; `TIRE_PROFILES.*.wetGrip` is never read. Values differ from US-03 (street on gravel 0.5 vs 0.4; wet drag +10% vs +15%).
- **P15-06:** `LapManager.reset()` clears `bestLapTime`, so the first lap after any track load counts as a PB and `src/main.ts:256-258` overwrites the stored PB ghost even if slower. The "previous lap" ghost is saved but never shown (US-05 requires both).
- **P15-07:** `cycleTrack()` (`src/main.ts:391`) always loads `currentRaceIndex + 1` and never cycles further; the season stays on the old round, so a finished race is recorded against the wrong track.
- **P15-08:** `@keyframes pulse` (`index.html:409`) animates opacity and overrides the inline `opacity: 0`; computed opacity 0.6 while `wrongWay` was false.
- **P15-09:** `requestAnimationFrame(this.gameLoop.bind(this))` every frame (`src/main.ts:823`); object literals per tick at `src/main.ts:685`, `:781`; `TrackSpline.findClosestT` / `evaluateSurface`, `InputManager.getInputState`, `TouchController.getInput`, `SlipstreamManager.update` return new objects per tick. Contradicts `AGENTS.md` and P07/P09.
- **P15-10:** `loadTrack()` removes the old `trackGroup` without disposing geometry/materials. `renderer.info.memory.geometries` went 117 to 147 over six reloads.
- **P15-11:** not built: Time Trial mode, Quick Race, main menu, pause, settings (`apex_settings` never written), player name, guardrail collisions, WebGL context-loss handling, audio suspend on `visibilitychange`, third sprint (plan: 5 circuits / 3 sprints; code: 6 / 2). No scope cuts in the Decisions Log.
- **P15-12:** Playwright is not installed though `AGENTS.md` lists `npx playwright test`; the plan's E2E journeys don't exist. `tests/smoke.test.ts` is three tautologies. `localStorage` persistence is never exercised (no DOM environment).
- **P15-13:** AI run at constant speed with no corner slowdown; `QualifyingManager.ts:43` compares `terrainAffinity` to itself; collision pushes on AI are overwritten next tick by `updateCarTransform`; AI race times are derived from the player's.
- **P15-14:** `public/sw.js` precaches only the page and icons; the hashed JS bundle is cached on the second visit.
- **P15-15:** `og:image` / `twitter:image` are `/icons/icon-512.svg`. Major platforms need an absolute URL and a raster image; validators not run. iOS home-screen icon is also SVG.
- **P15-16:** if the page reloads after the finale but before "new season", round 8 loads again and can be scored twice (`seasonCompleted` not checked).
- **P15-17:** `window.__game` debug global (`src/main.ts:245`); dead file `src/engine/RivalDrone.ts` (knip); CSP allows `'unsafe-inline'` scripts and Google Fonts nothing uses; touch overlay covers the tire card on any window ≤1024px; hardcoded colours at `src/ui/HUDController.ts:588,592`; `SETUP.md` says "pending initial commit"; walkthrough links in PROGRESS.md point outside the repo.
